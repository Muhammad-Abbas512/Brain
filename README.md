# 🧠 Human Brain & Memory Quiz

A simple and interactive **quiz web application** designed to test users’ knowledge about the human brain, memory types, and cognitive functions.

## 📖 About the Project

This project is an **educational quiz app** focusing on the human brain and memory types.  
Users can learn and test their knowledge on key concepts such as:

- Human brain structure  
- Memory types and processing  
- Cognitive functions  

---

## ✨ Features

- 🧩 Multiple-choice questions  
- ✅ Instant feedback on answers  
- ⏱ Optional timer per question  
- 📊 Tracks correct answers  
- 📱 Fully responsive layout  

---

## 🛠️ Technologies Used

- **HTML5** – Semantic markup for content and structure  
- **CSS3** – Styling, animations, and responsive layout  
- **JavaScript** – Quiz logic, scoring, and timer  
- **Git & GitHub** – Version control  

---

## 📁 Example Questions / Concepts

- **HPP** – Hypothetical Processing Pathway  
- **HCP** – Human Connectome Project  
- **HMP** – Hippocampal Memory Processing  
- **STM** – Short-Term Memory  
- **SM** – Sensory Memory  
- **LTM** – Long-Term Memory  
- **PS** – Procedural / Semantic Memory  
- **Human Brain** – Basic structure and functions  

> Each abbreviation can be used as a multiple-choice question in the quiz.
